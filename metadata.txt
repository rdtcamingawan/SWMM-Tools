name=SWMM Tools
qgisMinimumVersion=3.16
description=Configure SWMM layers and allows assignment of subcatchment outlets, and calculate width from longest flowpath.
about=SWMM Tools is a companion plugin for Generate SWMM Inp. It stores which layers and fields the plugin should use in the QGIS project. Assign Outlet lets you click a subcatchment then a junction or outfall to write the node ID into the subcatchment outlet field. Calculate Width clips longest-flowpath lines to each subcatchment and writes Width = Area / Longest Flowpath. Field names default to Outlet, Name, and Width but can be configured.
