description=Configure SWMM layers and allows assignment of subcatchment outlets in QGIS.
about=SWMM Tools is a companion plugin for Generate SWMM Inp, intended to assign subcatchment outlet without opening the attribute table. Version 1.0 has two tools: Configure Layer stores which layers should the plugin use and stores the layer_id and layer_name in the QGIS Project. Assign Outlet lets the user click a subcatchment then a junction/outfall layer to write the node's "Name" into the subcatchment "Outlet" field. Field names "Outlet" and "Name" are required.
